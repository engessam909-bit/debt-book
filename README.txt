دفتر الديون — إصدار PWA
========================

محتويات الحزمة
- index.html: التطبيق العربي.
- manifest.webmanifest: تعريف التطبيق القابل للتثبيت.
- sw.js: التخزين المؤقت والعمل دون اتصال بعد التحميل الأول.
- icon-192.png و icon-512.png: أيقونات التثبيت.
- icon.svg: أيقونة المتصفح.

طريقة النشر والتثبيت على Samsung Galaxy A56
1) ارفع جميع الملفات الموجودة داخل هذا المجلد إلى استضافة مواقع تدعم HTTPS، مع إبقاء الملفات في مجلد واحد. أمثلة: GitHub Pages أو Netlify.
2) افتح رابط الموقع المنشور باستخدام Google Chrome على الهاتف.
3) انتظر اكتمال التحميل أول مرة، ثم من قائمة Chrome اختر «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
4) افتح «دفتر الديون» من أيقونته. بعد نجاح التحميل والتخزين المؤقت يمكن فتح التطبيق دون اتصال.

ملاحظات مهمة
- لا يمكن تثبيت PWA من ملف HTML المفتوح مباشرة بصيغة file://؛ يلزم رابط HTTPS أو localhost.
- البيانات تُحفظ محليًا في متصفح هذا الجهاز فقط، ولا توجد مزامنة سحابية أو مشاركة تلقائية بين الأجهزة.
- صدّر نسخة Excel احتياطية بانتظام، خصوصًا قبل تغيير الهاتف أو حذف بيانات المتصفح.
- تم إعداد مكتبة Excel للتخزين المؤقت أثناء التثبيت إذا كان الإنترنت متاحًا. إذا لم تُحمّل لأي سبب، استخدم اتصال الإنترنت عند أول استيراد/تصدير Excel.
- مشاركة النص تستخدم قائمة المشاركة في أندرويد عند توفرها. مشاركة الصورة ترسل PNG مباشرة إذا كان المتصفح يدعم مشاركة الملفات، وإلا يتم تنزيلها لتُرفق يدويًا في واتساب.
- ميزانية السداد الشهرية المستهدفة اختيارية، ولا تضع حدًا للمبالغ التي يمكن تسجيلها. اتركها فارغة لإخفاء المقارنة.
